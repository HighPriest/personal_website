# Amun.pl FrontPage

Amun.pl frontpage SinglePageApplication, written in Svelte & hosted with Deno

## Used dependencies
- sveltekit-adapter-deno
- sass-embedded
- inlang/paraglide
- ??@tanstack/svelte-table  // For creating beautiful & dynamic tables
- ??@tanstack/svelte-query  // For running REST api queries
- ??@tanstack/svelte-virtual    // For holding long lists of data
- ??embla-carousel-svelte   // For beautiful carousels & image showcases
- ??sveltekit-superforms    // For creating forms
